ADI INTERNATIONAL — SITE STATIQUE DE DEMONSTRATION

Contenu
- index.html : page d'accueil
- assets/style.css : styles et affichage mobile
- assets/app.js : bascule français/anglais et formulaire de démonstration

Installation
1. Décompressez le ZIP.
2. Pour un hébergement cPanel, ouvrez le Gestionnaire de fichiers.
3. Ouvrez le dossier racine du domaine (souvent public_html).
4. Téléversez le contenu du ZIP directement dans ce dossier.
5. Vérifiez que index.html se trouve à la racine, puis ouvrez votre domaine.
